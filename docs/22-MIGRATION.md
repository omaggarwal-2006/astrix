# 22 · Repo Restructure: Migration Record and Next Steps

What changed when the repo moved to the `src/` layout (14 Nov 2026), how it was checked, and what's left. The target structure is in [06-ARCHITECTURE.md](06-ARCHITECTURE.md).

> **Later the same day, the UI was redesigned around the decision loop (D-18).** `overview.js`, `monitor.js`, `sources.js` and `controls.js` below were replaced by `today.js`, `signals.js`, `evidence.js`, `twin-tab.js` and `simulation.js`. The current view list is in [19-UI_GUIDE.md](19-UI_GUIDE.md#as-built-14-nov-2026).

## Why

| Problem before | Fix |
|---|---|
| One 1,771-line `main.js` held state, routing, all five tabs, the twin, the demo runner and reset | Split into `src/app/` (state, router) and 14 `src/ui/` modules |
| Logic files scattered in the repo root | Moved to `src/core/`; sample data to `src/data/` |
| About a third of the files were never loaded | Deleted (decision D-12) |
| One 1,436-line stylesheet organised by build step | 11 files in `assets/css/` by responsibility; 9 dead rules removed |
| Hand-written service-worker file list | Generated by `scripts/build-sw-manifest.mjs`; CI checks it |
| Tests that only printed output or checked strings | 33 behaviour tests with Node's test runner, plus the smoke check |
| No `package.json`, CI, line-ending rules or license notes | Added |
| Thresholds and the delay formula copied across files | `src/core/config.js` and `src/core/delay.js` |

## Behaviour changes (intended)

The restructure was meant to change no behaviour. These are the deliberate exceptions:

| Change | Why |
|---|---|
| Only the visible tab re-renders on a day change (others render when opened) | Speed (N4, decision D-17); the old code rebuilt all five tabs on every scrubber step |
| The service worker caches files one by one and skips cross-origin requests; cache renamed `landfall-v6-src-layout` | One missing file no longer breaks offline mode; the old v5 cache is deleted on activate |
| The duplicate inline `onclick` on the title button and the second title handler in `main.js` are gone | The inline script in `index.html` already covers it, even if a module fails to load |
| Header and mission scene read the delay from `src/core/delay.js` | Same formula, one place (D-05) |
| Triage and queue read their numbers from `src/core/config.js` | Same values (live-call limit 300 s, persistence 5 days, speedup 100, fail rate 0.1, retry 2 s) |

## Working in the new layout

| I want to… | Go to |
|---|---|
| Change a threshold | `src/core/config.js` (and [18 §7](18-DATA_MODEL.md#7-configuration) + a decision) |
| Change how triage decides | `src/core/triage.js` + `tests/unit/triage.test.mjs` |
| Change a tab | `src/ui/tabs/<tab>.js` + `assets/css/tabs/<tab>.css`; markup still in `index.html` until step 5 |
| Add a runtime file | Create it, then `npm run build:sw` |
| Add a test | `tests/unit/<name>.test.mjs` (pure logic) or `tests/integration/` (several modules together) |
| See what the app loads | `index.html` (styles and scripts) and `src/main.js` (what starts) |
